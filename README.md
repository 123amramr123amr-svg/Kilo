# منارة | مجموع منهج الصف الثالث الثانوي 2027 — مصر

تطبيق ويب شامل (يعمل بدون إنترنت) يحتوي **جميع مواد** الصف الثالث الثانوي المصري بشرح مبسط واختبارات لكل درس ووحدة ومنهج كامل، مع خطط مذاكرة ذكية تراعي وقت النوم، منبّه مذاكرة، تايمر، جدول دروس، وتوليد خطة بالذكاء الاصطناعي.

## التشغيل

افتح ملف `index.html` في أي متصفح (Chrome / Edge / Firefox / Safari) — لا يحتاج سيرفر أو تثبيت أو إنترنت. تُحفظ بياناتك (التقدم، الخطة، المنبّهات) محليًا على جهازك.

> ملاحظة: المحتوى مبني على أحدث نسخة متاحة من المنهج المصري (2024–2025) ومنهج 2027 لم يُنشر بعد — التطبيق مصمم ليُحدَّث بسهولة بإضافة دروس في ملفات `js/data/`.

## المميزات

- **📖 شرح مبسط**: كل درس في نقاط مركّزة + أمثلة محلولة.
- **📝 اختبارات**: 3 أسئلة لكل درس، امتحان لكل وحدة، اختبار كامل لكل مادة — مع تصحيح فوري ومراجعة الأخطاء وحفظ أفضل نتيجة.
- **🧠 خطة مذاكرة ذكية**: أدخل وقت الاستيقاظ والنوم، أيام الدراسة، موعد الامتحان، وأولويات المواد — يحسب خطة أسبوعية **تراعي**:
  - وقت النوم (لا حصص بعد موعد النوم، وتنبيه "استعد للنوم" قبله بـ30 دقيقة)
  - مواعيد دروس المدرسة (تُتجنب تلقائيًا)
  - الدروس الضعيفة (أقل من 60% تُراجع أولًا بأعلى أولوية)
  - أوقات التركيز (المواد الأصعب في 8–11 صباحًا و5–9 مساءً)
- **🤖 توليد بالذكاء الاصطناعي (اختياري)**: عبر مفتاح API (مثل OpenAI) يُنشئ خطة مكتوبة كاملة — والخطة الذكية المحلية تعمل بدون إنترنت بالكامل.
- **⏰ منبّه مذاكرة**: منبّهات بوقت ووصف وأيام تكرار + صوت تنبيه + إشعارات المتصفح.
- **⏲ تايمر بومودورو**: 25/5، 50/10، أو مخصص — مع سجل جلسات اليوم.
- **🏫 جدول الدروس**: أضف مواعيد دروسك في المدرسة لتُبنى الخطة حولها.
- **🔍 بحث فوري** عن أي درس أو مادة + تتبع التقدم بنسبة مئوية لكل مادة.

## هيكل الملفات

```
index.html          — صفحة التطبيق
css/style.css       — التصميم ( RTL )
js/app.js           — الواجهة والاختبارات والتايمر والمنبّهات
js/planner.js       — محرك الخطة الذكية + واصلة الذكاء الاصطناعي
js/data/*.js        — بيانات المنهج (مادة في كل ملف)
```

## لتحديث المنهج (2027)

أضف درسًا في ملف المادة بالصيغة:

```js
{id:'mth-u1-l99', title:'عنوان الدرس', p:['نقطة 1','نقطة 2',...], ex:['مثال 1',...],
 q:[{q:'السؤال؟', o:['اختيار1','اختيار2','اختيار3','اختيار4'], a:2, w:'التفسير'}]}
```
حيث `a` رقم الإجابة الصحيحة (0-3).

## الخصوصية

كل البيانات (التقدم، الخطة، المنبّهات، الإعدادات) محفوظة في `localStorage` على جهازك فقط، ولا يُرسل شيء لأي خادم إلا عند استخدام توليد الخطة بالذكاء الاصطناعي بمفتاحك الشخصي.
