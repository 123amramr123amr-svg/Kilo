# LensAI - تطبيق كاميرا احترافي بالذكاء الاصطناعي

تطبيق كاميرا احترافي يستخدم الذكاء الاصطناعي لمساعدة المستخدم على التقاط صور و فيديوهات أفضل.

## الميزات الرئيسية

- **وضع الصورة**: للrectangle العادي و البورتريه و الطعام و المناظر الليلية
- **وضع الفيديو**: لrectangle فيديو ثابت و واضح مع خيارات الدقة و معدل الإطارات
- **الوضع الاحترافي Pro**: تحكم يدوي في ISO، سرعة الغالق، التركيز، توازن اللون الأبيض، والتعريض
- **مساعد الذكاء الاصطناعي**: يحلل المشهد و يعطي اقتراحات ذكية
- **محرر صور مدمج**: قص، إضاءة، تباين، ألوان، حدّة
- **معرض منظم**: ترتيب حسب التاريخ، الألبومات، المفضلة
- **الوضع الداكن**: واجهات مريحة للعينين

## التقنيات المستخدمة

- Expo + React Native
- TypeScript
- Reanimated للحركة السلسة
- expo-camera للوصول إلى الكاميرة الحقيقية
